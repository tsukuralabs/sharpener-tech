💰 How to View the Expense Tracker Project

To view the Expense Tracker project:

Open the repository: https://github.com/tsukuralabs/sharpener-tech
Search for the expense.js and index.html files.
Open index.html to view the project’s HTML structure and expense.js to view its JavaScript functionality.

You can run the project locally by opening index.html in your browser or using the Live Server extension in Visual Studio Code.
