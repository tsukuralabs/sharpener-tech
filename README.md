📂 Repository Contents
1. Expense Tracker 💰

A simple Expense Tracker web application built using HTML, CSS, and JavaScript.

Features:

Add new expenses with amount, description, and category.
Edit existing expenses.
Delete expenses.
Store expense data using browser localStorage.
Retain saved expenses after refreshing the page.

Technologies Used:

HTML5
CSS3
JavaScript
Bootstrap 5
Browser Local Storage

🚀 Getting Started

To run the Expense Tracker locally:

Clone the repository:
git clone https://github.com/tsukuralabs/sharpener-expense-tracker.git

Open the project folder:
cd sharpener-expense-tracker

Open index.html in your browser or use the Live Server extension in Visual Studio Code.
