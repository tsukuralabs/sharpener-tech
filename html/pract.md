Here is the complete chronological list of the questions you have asked, formatted as an exam review sheet with the correct options and final answers:
## 1. Document Background Color

* Question: Select the correct answer which set the background color of the document to yellow.
* Correct Answer: <body style="background-color: yellow;"> (or body { background-color: yellow; } in CSS).

## 2. Anchor Link Syntax

* Question: Complete the syntax or correct it if wrong: <a href="https://w3schools.com">This is a link
* Correct Answer: <a href="https://w3schools.com">This is a link</a> (Added the missing closing tag).

## 3. HTML Inventor

* Question: Who invented HTML?
* Correct Answer: Tim Berners-Lee in 1989.

## 4. HTML Tooltip Attribute

* Question: How to add the tooltip: <p ="About W3Schools">W3Schools is a web developer's site.</p>
* Correct Answer: <p title="About W3Schools">W3Schools is a web developer's site.</p> (Added the title attribute).

## 5. Paragraph Line Breaks (True/False)

* Question: True or False. HTML paragraphs always start on a new line.
* Correct Answer: True (Because <p> is a block-level element).

## 6. Manual Line Breaks

* Question: Add a line break in the middle of the paragraph: <p>My Bonnie lies '/n' over the ocean.</p>
* Correct Answer: <p>My Bonnie lies<br>over the ocean.</p> (Replaced '\n' with <br>).

## 7. Preserving Spaces and Poem Layout

* Question: Wrap this poem around HTML tags that will preserve all spaces and linebreaks: My Bonnie lies...
* Correct Answer: Wrap it in the <pre> tag:

<pre>
 My Bonnie lies over the ocean.
  My Bonnie lies over the sea.
</pre>


## 8. Inline Text Styling (Color)

* Question: Use the correct HTML attribute, and CSS, to set the color of the paragraph to "blue": <p style="text:'blue;">This is a paragraph.</p>
* Correct Answer: <p style="color: blue;">This is a paragraph.</p> (Corrected property to color).

## 9. Bold Text Elements

* Question: Two of the following HTML elements make the text bold, which two?
* Options: <em> and <b> | <strong> and <b> | <big> and <b> | <mark> and <b>
* Correct Answer: <strong> and <b>

## 10. Adding Extra Importance

* Question: Add extra importance to the word "degradation" in the paragraph: WWF's mission is to stop the degradation...
* Correct Answer: <strong>degradation</strong>

## 11. Emphasizing Text

* Question: Emphasize the word "metropolitan" in the text below: ...the most populous metropolitan area...
* Correct Answer: <em>metropolitan</em> (Renders text as italics).

## 12. Text Highlighting

* Question: Highlight the word "FUN" in the text below: <p>HTML is FUN to learn!</p>
* Correct Answer: <mark>FUN</mark> (Creates a yellow background highlight by default).

## 13. Subscript Formatting

* Question: Apply subscript formatting to the number "2" in the text: <p>H<sub>2O is the scientific term...
* Correct Answer: H<sub>2</sub>O (Closed the subscript tag correctly).

## 14. Strikethrough Text

* Question: Add a line through (strikeout) the letters "blue" in the text: <p>My favorite color is blue red.</p>
* Correct Answer: <del>blue</del> (or <s>blue</s>).

## 15. Invalid Quotation Element

* Question: Which of the following is NOT a quotation element (in fact, not an HTML element at all)?
* Options: <q> | <quote> | <blockquote>
* Correct Answer: <quote> (This tag does not exist in standard HTML).

## 16. Short Inline Quotes

* Question: Use an HTML element to add quotation marks around the letters "cool": <p>I am so cool.</p>
* Correct Answer: <q>cool</q>

## 17. Extended Block Quotes & Citations

* Question: The text below should be a quoted section. Add the proper HTML element and specify the source URL.
* Correct Answer:

<blockquote cite="http://worldwildlife.org">
For 50 years, WWF has been protecting...
</blockquote>


## 18. Text Direction (Right-to-Left)

* Question: Change text direction. Make the text below go right-to-left: What a beautiful day!
* Correct Answer: <bdo dir="rtl">What a beautiful day!</bdo>

* Correct Answer: A tooltip is a small informational text box that appears dynamically when a user hovers their mouse pointer over an element on a screen.
