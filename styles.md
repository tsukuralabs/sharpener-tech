## Row in BootStrap

- Row is using flexbox in bootstrap.
- Row is 1/12th size of column.

```css
/* this is how we can define the row */
<div class="row"></div>
```

## Col in BootStrap
- The col class in Bootstrap is used to **create equal-width columns that automatically resize to fit** the available space within a row, without requiring a specific numeric span.  
- It is part of Bootstrap's **12-column grid system**, where the total width is divided into 12 parts.
