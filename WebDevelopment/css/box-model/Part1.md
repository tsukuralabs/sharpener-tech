📦 What is the CSS Box Model?
Core Definition: Every single element on a web page is represented as a rectangular box. The CSS Box Model describes how these boxes are structured, sized, and how they interact with surrounding elements in terms of spacing.

Role in Web Design: It acts as the foundational building block for controlling layout, spacing, sizing, alignment, and positioning in web development.

🧱 The 4 Core Layers of the Box Model
From the inside out, the box model consists of four distinct areas:

Content Area:

The innermost part where the actual content (text, images, videos, or child elements) lives.

Its dimensions are controlled using properties like width and height.

Padding:

Transparent space that sits directly around the content, inside the border.

Used to push the border away from the content and create breathing room inside the element.

Border:

A line that wraps around the padding (or content if there is no padding).

Defined using properties like border-width, border-style, and border-color.

Margin:

The outermost layer of transparent space that wraps around the border.

Used to separate the element from other neighboring elements on the web page.

📏 Controlling Box Dimensions & Properties
Width and Height: Applied to restrict or expand the inner content box.

Individual vs. Shorthand Spacing: Padding and margins can be set individually for each side (top, right, bottom, left) or using shorthand properties to keep your CSS clean and maintainable.
